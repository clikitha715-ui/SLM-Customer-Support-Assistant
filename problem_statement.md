# SLM Customer Support Assistant

## 1. Problem Statement
Many businesses receive a large number of customer queries every day. Handling these queries manually takes time and requires additional human support.

This project aims to develop a Small Language Model (SLM)-based Customer Support Assistant that can understand customer questions and generate relevant responses automatically.

## 2. Project Objective
- Build a customer support assistant using a Small Language Model.
- Understand and respond to customer queries.
- Reduce manual customer support workload.
- Provide quick and relevant responses.
- Optimize the model for efficient performance.

## 3. Technologies Used
- Python
- Hugging Face Transformers
- PyTorch
- FastAPI
- NLP
- Small Language Models

## 4. Expected Outcome
A working AI-powered customer support assistant that accepts customer questions and generates meaningful responses through an API.
